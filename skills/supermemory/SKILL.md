# Supermemory

Persistent memory for this Muse Code workspace.

## When to search

Call the supermemory `search_memory` MCP tool when the user refers to past decisions, earlier sessions, or says "remember" / "we decided" / "last time". Scope with this project's `namespace` when the question is about this repo.

## When to save

Call the supermemory save/add MCP tool when the user asks to remember something durable: a decision, preference, architecture note, or lesson. Do not save transient git state or unaccepted suggestions.

## How to cite

Every recalled fact is marked ◪. Keep the mark when you use it, and if you name the source say "from supermemory" — never "from memory".
